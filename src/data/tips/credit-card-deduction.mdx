## 카드 공제, 뭐가 다른가요?

| 구분 | 공제율 |
|------|--------|
| 신용카드 | **15%** |
| 체크카드·현금영수증 | **30%** |
| 도서·공연·박물관 | **30%** |
| 전통시장 | **40%** |
| 대중교통 | **40%** |

## 황금 비율 전략

카드 소득공제는 총급여의 **25%를 초과한 금액**부터 공제돼요.

> 예시: 총급여 5,000만원 → 연 1,250만원 쓴 이후부터 공제 시작

**전략:**
- 총급여의 25%까지는 → **신용카드** (포인트·혜택 챙기기)
- 25% 초과분부터는 → **체크카드·현금영수증** (공제율 2배!)

## 공제 한도

| 총급여 | 공제 한도 |
|--------|-----------|
| 7,000만원 이하 | 300만원 |
| 7,000만원~1.2억원 | 250만원 |
| 1.2억원 초과 | 200만원 |

## 꿀팁

- 전통시장·대중교통은 **추가 공제** 100만원씩 더 받을 수 있어요
- 배우자·자녀 카드 사용액도 합산 가능 (단, 연간 소득 100만원 이하인 가족)
- 의료비는 신용카드와 의료비 공제 **중복 적용** 가능!
