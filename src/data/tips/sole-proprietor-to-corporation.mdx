## 개인 vs 법인 세율 비교

| 과세표준 | 개인 소득세율 | 법인세율 |
|----------|---------------|----------|
| 1,200만원 이하 | 6% | - |
| 4,600만원 이하 | 15% | - |
| 8,800만원 이하 | 24% | - |
| **2억원 이하** | **35%** | **9%** |
| **2억~200억** | **38~45%** | **19%** |

> 소득이 많을수록 개인 세율과 법인 세율 차이가 커져요!

## 법인 전환 절세 포인트

1. **대표자 급여**: 법인 비용으로 처리 → 법인 소득 줄임
2. **4대 보험 절약**: 법인 대표는 4대 보험 부담 구조가 달라짐
3. **퇴직금 준비**: 법인 대표 퇴직금은 비용 처리 가능
4. **가족 고용**: 배우자나 자녀를 직원으로 고용해 급여 지급 (실제 근무 시)

## 전환 비용

| 항목 | 비용 |
|------|------|
| 법인 설립 비용 | 약 50~100만원 |
| 세무사 기장 월 비용 | 약 15~30만원 |
| 법인 설립 시간 | 2~4주 |

## 전환 기준 시점

- 연 순이익 **1억원 이상**이면 법인 전환 검토
- 동업자가 있거나 **투자 유치 계획**이 있을 때
- **부동산·자산 취득** 계획이 있을 때

세무사와 상담 후 결정하는 것을 강력 권장합니다.
