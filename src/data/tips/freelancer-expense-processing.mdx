## 프리랜서 절세의 핵심: 경비 처리

프리랜서는 **종합소득세** 신고 시 업무 관련 지출을 **필요경비**로 신고해 과세 소득을 줄일 수 있어요.

## 인정되는 경비 항목

| 항목 | 예시 |
|------|------|
| 업무용 장비 | 컴퓨터, 모니터, 카메라, 마이크 |
| 통신비 | 인터넷, 휴대폰 요금 (업무 비율만큼) |
| 교육비 | 직무 관련 강의, 책, 컨퍼런스 |
| 소프트웨어 구독 | 어도비, 노션, 슬랙 등 |
| 업무 공간 | 공유 오피스, 홈오피스 (임대료 일부) |
| 교통비 | 업무 관련 이동 (영수증 필수) |
| 식비 | 업무 미팅 식사 (영수증 + 메모 필수) |

## 단순경비율 vs 기준경비율

연 수입이 일정 금액 이하면 **단순경비율**로 간편하게 신고할 수 있어요.

| 업종 | 단순경비율 적용 기준 | 단순경비율 (예시) |
|------|---------------------|------------------|
| 서비스업 | 2,400만원 미만 | 40~60% |
| 도매업 | 6,000만원 미만 | 90% |
| 소매업 | 3,600만원 미만 | 80% |

## 실천 방법

1. **사업용 계좌·카드 분리** → 경비 증빙이 쉬워요
2. 모든 영수증 **사진 촬영 후 보관** (홈택스 간편 등록 활용)
3. 매년 5월 종합소득세 신고 시 경비 합산 신고
4. 불안하면 **세무사 기장 서비스** 활용 (월 3~10만원)
